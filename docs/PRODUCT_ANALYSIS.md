# Análise de produto

## Definição

ChurchOS é um SaaS multi-tenant para gestão de igrejas com duas superfícies principais: painel administrativo e portal mobile-first para membros.

## Referências oficiais

As três referências devem ser analisadas continuamente para produto, funcionalidades, UX e modelo de negócio, sem cópia visual ou de código:

- inChurch — https://inchurch.com.br/
- NossaIgreja.app — https://nossaigreja.app/
- GoChurch — https://gochurchapp.com.br/

### inChurch

Referência para ecossistema integrado, gestão de membros, células, comunicação, eventos, doações, conteúdo e operação de múltiplas igrejas/unidades.

### NossaIgreja.app

Referência para operação administrativa cotidiana, membros, financeiro, Kids, voluntários, células, eventos, louvor e organização por planos.

### GoChurch

Referência obrigatória adicional para UX, experiência igreja/membro, funcionalidades e estrutura do produto. Nenhuma funcionalidade deve ser atribuída à plataforma sem validação direta.

## Escopo de lançamento

Fundação + Auth + onboarding + multi-tenancy + RBAC + membros + visitantes + células + ministérios + eventos + presença + escalas + financeiro básico + notificações + dashboard + portal do membro + auditoria.
